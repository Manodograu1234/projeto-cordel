# 🌐 Projeto Cordel de Milton Santos  

Este projeto é um **site educativo** desenvolvido em **HTML e CSS**, apresentando o **Cordel de Milton Santos** e explorando diferentes tipos de **backgrounds e estilos visuais**.  

---

## 📌 Funcionalidades
- ✅ Conteúdo informativo sobre Milton Santos e seu cordel  
- ✅ Layout estilizado com diferentes tipos de **backgrounds** (gradientes, imagens e cores sólidas)  
- ✅ Seções bem estruturadas para facilitar a leitura  
- ✅ Efeitos visuais com CSS para destacar o conteúdo  
- ✅ Navegação simples entre as seções do site  

---

## 🛠 Tecnologias
- **Front-end:** HTML5, CSS3  
- **IDE:** VS Code  
- **Extras:** CSS Gradients, Background Images, Hover Effects
